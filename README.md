# Imputation-free Learning of Tabular Data with Missing Values using Incremental Feature Partitions in Transformer
## Installation
To set up this project locally:

1. Download the repository and go to the `ifial` directory:
   ```bash
   cd ifial
   ```
2. Install or create a new Conda environment using `env.yml`:
   ```bash
   conda env create -f env.yml
   conda activate conda-ifial
   ```
3. Navigate to the `exmples` folder:
   ```bash
   cd exmples
   ```
4. Open and run the example notebook:
   ```bash
   jupyter notebook ifial.ipynb
   ```
